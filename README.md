# ReThink

ReThink is a sustainable technology initiative aimed at promoting responsible recycling habits. The platform simplifies the recycling process by providing users with an accessible system to track, manage, and verify their contributions to environmental sustainability.

---

## 🚀 Features

* **Secure User Authentication:** Implements JWT-based authentication for robust user sessions and data security.
* **Email Verification System:** Utilizes Brevo API for transactional emails, ensuring reliable communication.
* **Firebase Integration:** Leverages Firebase for real-time data management and scalable backend operations.
* **Recycling Tracking:** A streamlined interface for users to log and monitor their recycling activities.
* **Environment-Based Configuration:** Secure handling of all sensitive API credentials and project secrets.

---

## 🛠 Technologies

* **Backend:** Node.js, Express.js
* **Frontend:** HTML, CSS, JavaScript (Hosted on GitHub Pages)
* **Database & Services:** Firebase (Auth, Firestore), Google APIs
* **Security:** JWT (JSON Web Tokens)
* **Email Service:** Brevo API
* **Deployment:** Render, GitHub Pages
* **Version Control:** Git & GitHub

---

## ⚙️ Setup Instructions

To run this project locally, follow these steps:

1. **Clone the repository:**
```bash
   git clone [https://github.com/](https://github.com/)[YourUsername]/ReThink.git
   cd ReThink

```

2. **Install the dependencies:**

```bash
   npm install

```

3. **Configure environment variables:**
Create a `.env` file in the root directory and add the following keys based on your project configuration:

```env
   APP_URL=
   BREVO_API_KEY=
   EMAIL_PASS=
   EMAIL_USER=
   FIREBASE_CLIENT_EMAIL=
   FIREBASE_PRIVATE_KEY=
   FIREBASE_PROJECT_ID=
   GOOGLE_CLIENT_ID=
   JWT_SECRET=

```

4. **Start the application:**

```bash
   npm start

```
